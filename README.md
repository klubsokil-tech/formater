# Academic DOCX Formatter

Готовий Node.js-проєкт для автоматичного форматування академічних Word-документів (`.docx`).

## Що робить програма

- Аналізує абзаци та призначає:
  - **Heading 1** для `ВСТУП`, `ВИСНОВКИ`, `СПИСОК ВИКОРИСТАНИХ ДЖЕРЕЛ` і рядків за шаблоном `^РОЗДІЛ\s+\d+`
  - **Heading 2** для рядків за шаблоном `^\d+\.\d+`
- Створює автоматичний зміст (TOC) на основі Heading 1/2.
- Додає розрив сторінки перед кожним Heading 1.
- Форматує текст:
  - Times New Roman
  - 14 pt
  - вирівнювання по ширині
  - міжрядковий інтервал 1.5
  - відступ першого рядка 1.25 см
- Встановлює поля сторінки:
  - верх/низ — 2 см
  - ліве — 3 см
  - праве — 1 см
- Очищає текст від подвійних пробілів і порожніх рядків.
- Вставляє випадкові посилання у форматі `[номер, с. сторінка]` рандомна встака в тексті (без повторів підряд).
- Додає список джерел, якщо його немає у вхідному документі.
- Дає змогу перевірити результат через `verify.js`.

---

## Важливо перед запуском

Щоб працював запуск подвійним кліком (`run-format.bat` / `run-format.sh`), на ПК має бути встановлено:

- **Node.js LTS** (разом із `npm`)
- доступ до інтернету для першого `npm install`

Якщо Node.js не встановлено, лаунчер покаже зрозуміле повідомлення і підкаже, що робити далі.

---

## Варіант 1 (через термінал)

```bash
npm install
node formatDocx.js input.docx output.docx
node verify.js output.docx
```

Для вашого файлу:

```bash
node formatDocx.js "Розділ_3_Практичний_аналіз_функціонування_іншомовної_лексики_в_корейських.docx" output.docx
```

---

## Варіант 2 (без ручної роботи в терміналі)

### Windows
1. Перетягніть ваш `.docx` на `run-format.bat` **або** покладіть файл у папку проєкту (скрипт автоматично знайде `input.docx`, типовий файл з прикладу або перший доступний `.docx`).
2. Запустіть подвійним кліком `run-format.bat`.
3. Готовий файл буде `output.docx`.

> `run-format.bat` автоматично перемикає консоль у UTF-8 (`chcp 65001`), щоб коректно обробляти кириличні шляхи у Windows.

### macOS / Linux
1. Покладіть цей самий `.docx` у папку проєкту.
2. Запустіть `run-format.sh` (подвійний клік або через файловий менеджер).
3. Готовий файл буде `output.docx`.

## Варіант 3 (Web UI: вибір файлу + прогрес + звіт)

```bash
node server.js
```

Потім відкрийте в браузері `http://localhost:3000`:
1. Оберіть `.docx` файл.
2. Натисніть **Запустити форматування**.
3. Спостерігайте прогрес виконання, лог кроків і підсумковий звіт перевірки.
4. Завантажте готовий файл через кнопку в блоці звіту.

---


### Опційні параметри редагування (Web UI)

У Web UI усі налаштування можна вмикати/вимикати перед запуском:
- Параметри сторінки: поля (2/2/3/1 см) та книжкова орієнтація.
- Текст: Times New Roman 14 pt, інтервал 1.5, відступ 1.25 см, вирівнювання по ширині.
- Структура: розриви сторінок перед розділами, заголовки (жирний/по центру/чорний), порожні рядки до/після заголовків.
- Посилання: випадкові цитати `[номер, с. сторінка]` та уніфікація квадратних дужок.
- Список джерел: додавати за потреби, сортувати (`order` або `alpha`) або вставити свій список джерел у Web UI (по одному на рядок).
- Збереження спецконтенту: корейські символи не змінюються.

## Примітка

Скрипт працює з текстовим вмістом DOCX і формує новий відформатований документ. Якщо у вхідному файлі є складні об'єкти (наприклад, таблиці/зображення), вони можуть не переноситися в результат.
