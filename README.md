# formater

CLI-утиліта для базового форматування `.docx` файлів: додає TOC-поле, вставляє блок цитувань і бібліографію, а також виконує базову нормалізацію тексту.

## Швидкий старт

1. Встановіть залежності:

```bash
npm install
```

2. Запустіть форматування:

```bash
node formatDocx.js input.docx output.docx
```

3. (Опційно) Перевірте результат:

```bash
node verify.js output.docx
```

## Очікуваний результат

Після виконання команди ви отримаєте новий файл `output.docx`, у якому:
- на початку документа вставлене поле змісту (TOC),
- у кінці додані блоки "Цитування" та "Список використаних джерел",
- зайві повторювані пробіли в текстових вузлах зменшено до одного.

> Для оновлення відображення змісту відкрийте документ у Microsoft Word та натисніть `F9` на полі TOC.
